# Deep Learning Specialization

**DeepLearning.AI | Andrew Ng**

A personal educational archive of my work completed as part of the five-course Deep Learning Specialization offered by DeepLearning.AI and taught by Andrew Ng.

**Learner:** Md. Zubayer Ahmad Shibly

## About the Specialization

The Deep Learning Specialization covers neural network foundations, optimization, machine learning project strategy, computer vision, and sequence models.

## Courses

1. **Neural Networks and Deep Learning**
   - Neural networks, backpropagation, vectorization, and deep architectures.

2. **Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization**
   - Initialization, regularization, optimization algorithms, and hyperparameter tuning.

3. **Structuring Machine Learning Projects**
   - Error analysis, bias and variance, and machine learning development strategy.

4. **Convolutional Neural Networks**
   - CNNs, object detection, face recognition, and neural style transfer.

5. **Sequence Models**
   - RNNs, GRUs, LSTMs, word embeddings, attention mechanisms, and Transformers.

## Technologies and Concepts

Python, NumPy, TensorFlow, Keras, Jupyter Notebook, Deep Learning, CNNs, RNNs, LSTMs, GRUs, and Transformers.
